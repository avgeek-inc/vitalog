---
title: "Get started"
description: "Open the dashboard, connect your MCP client and log an observation."
---

<Steps>
  <Step title="Open Vitalog">
    Open your installation's UI and sign in with its configured root email and password. The example UI is `https://vitalog.praveent.com`; its API is `https://vitalog-api.praveent.com`.

    For your own installation, follow [Installation](/installation) first.

  </Step>
  <Step title="Connect a client">
    Open **Settings → MCP Guide**, choose your client and copy its configuration. Clients connect to the API's `/mcp` URL. Approve the OAuth request on Vitalog's consent page.

    For a script or client using a Bearer key, create a key in **Settings → API Keys**. It expires after 30 days. See [MCP setup](/mcp-guide) and [API keys](/api-keys).

  </Step>
  <Step title="Log an observation">
    Ask your MCP client to record an observation you supply, such as a glass of water or a mood check-in. The client can discover the exact input schema with `health_get_catalog` before using a logging tool.

    Every write needs an idempotency key. Missing measurements must remain missing rather than being inferred. See [record contracts and examples](/records).

  </Step>
  <Step title="Review the day">
    Open **Stats → Daily View**. Select a date using the calendar beside the title. Expand a log to see its details. **Weight Management** shows current weight, a 30-day graph and weigh-ins.

    Set targets through [MCP or REST goals](/goals) to add progress bars. The UI does not create or edit health records.

  </Step>
</Steps>
