Vitalog is a single-user health ledger backed by PostgreSQL. Record the observations you supply, retain their source and revisions, and review daily totals and weight progress.

## Set goals, review progress

Set a weight target with an explicit start weight. Nutrition goals are upper limits; water, active calories and exercise minutes are minimum targets. The dashboard shows progress against the goals effective on the selected day.

The dashboard is read-only. Create or correct health records and goals through [MCP](/mcp-guide) or the [REST record contracts](/records). API Keys is a separate credential-management screen.

## Keep the original observation

Records retain their reported dates, timezones, units and provenance. Missing values remain unknown. Corrections and voids preserve previous revisions, and retry keys prevent an identical write from creating a duplicate.

Vitalog stores observations and user-defined goals. It does not diagnose conditions or prescribe health targets.
